# Demos

This directory contains standalone scripts demonstrating various concepts related to this project, such as masks and Fourier transforms.

## Available Demos

- `debug_angular_distribution.py`: Debug script for angular distribution.
- `fourier_synthetic_demo.py`: Demo showing synthetic Fourier transforms.
- `log_magnitude_demo.py`: Demo on log magnitudes.
- `spatial_difference_mask_demo.py`: Demo for spatial difference masks.

## Running the Demos

To keep the repository clean, the resulting images are **not included**. You must generate them yourself by running the scripts directly. For example:

```bash
python fourier_synthetic_demo.py
```
*(Repeat for other scripts as needed)*
