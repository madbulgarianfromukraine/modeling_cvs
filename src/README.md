# Source Code (src)

This folder contains the core Python source code and notebooks for the project. 

## Structure
- `analysis/`: Code for model/data analysis and visualization.
- `cleanup/`: Utilities for notebook cleanup.
- `data/`: Dataset handling, loading, and pre-processing scripts.
- `simple_model/`: Core implementations for basic modeling approaches.
- `utils/`: General utility functions and helpers.

## Notebooks
The following Jupyter notebooks are available for experimentation and analysis:
- `data/dataset_analysis.ipynb`: Analysis of the main datasets used in this repository. 
- `simple_model/analysis.ipynb`: The main analysis notebook for models. Execute it to see visualizations and results.
- `simple_model/baselines.ipynb`: Baseline implementations and metrics.
- `simple_model/simple_example.ipynb` & `simple_tiny_example.ipynb`: Simple demonstrations of training/inference.

### Running Notebooks
To run the notebooks, start a Jupyter instance from the root of the repository:
```bash
jupyter notebook
```
Navigate to the respective notebook path and execute the cells.
